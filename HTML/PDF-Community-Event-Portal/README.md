# Local Community Event Portal

Beginner project based on the four Module 1 PDFs: HTML5, CSS3, JavaScript, and Bootstrap 5.

## How to open

Open `index.html` in Chrome. Use DevTools to inspect elements, view console logs, test responsive layouts, and watch JavaScript variables.

## PDF checklist

- HTML5: base template, comments, semantic navigation, internal CSS, inline style, IDs/classes, gallery table, registration form, feedback events, video `oncanplay`, storage, geolocation, and debugging logs.
- CSS3: inline/internal/external CSS, comments, selectors, HEX/RGBA colors, background image, gradients, typography, link/list styling, table styling, box model, multi-column bulletin, and media query under `768px`.
- JavaScript: external `main.js`, console log, alert on load, `const`/`let`, template literals, conditions, loops, try/catch, functions, closures, callbacks, constructor/class, prototype method, `Object.entries()`, arrays, DOM rendering, events, mock async fetch with `.then()` and `async/await`, form handling, simulated POST, debugging logs, and jQuery click/fade.
- Bootstrap 5: CDN setup, bundle JS, responsive grid, `container/row/col-*`, sidebar/content layout, alignment, reordering, flex utilities, typography utilities, forms, buttons, button groups, responsive navbar, tabs/pills, cards, spacing, colors, visibility utilities, borders, shadows, rounded corners, fixed footer, absolute badge overlay, Bootstrap Icons, modal, accordion, and Sass variable sample in `scss/custom-bootstrap.scss`.

## Main files

- `index.html`: full event portal and Bootstrap component demos.
- `register.html`: registration form with validation and mock API submission.
- `feedback.html`: event handling, localStorage/sessionStorage, phone validation, and character counter.
- `styles.css`: CSS3 module styles.
- `main.js`: JavaScript module logic.
- `help.html`: external help document opened with `target="_blank"`.
